Tracking links

Add ?ref= to any link you post so it shows up as its own source. Lowercase letters, numbers, dashes. Examples:

  • gameboyretreat.com/?ref=tiktok
  • gameboyretreat.com/?ref=card — the QR on package inserts
  • gameboyretreat.com/?ref=gbp — Google Business Profile website link
  • gameboyretreat.com/shop?ref=reddit-webdev
  • gameboyretreat.com/listing/rayquaza-edition?ref=ig-story
